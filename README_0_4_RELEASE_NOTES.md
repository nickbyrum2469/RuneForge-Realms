# RuneForge Realms 0.4.0 Release Candidate

This branch is the Frontier Visual Survival milestone. See `docs/FRONTIER_VISUAL_SURVIVAL_0_4.md` for architecture and release-gate details.

Key player-facing additions include high-detail Frontier materials and sky/HUD rendering, three mining modes (Block/Micro/Mixed), physical 8×8×8 microvoxel carving, living grass and flowers, collectible world drops, a real survival inventory/hotbar, inventory-backed block placement, ornate native inventory presentation, and schema-3 persistence for the new state.
