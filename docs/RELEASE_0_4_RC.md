# RuneForge Realms 0.4.0 Release Candidate

See `FRONTIER_VISUAL_SURVIVAL_0_4.md` for the detailed architecture and release gate.

Player-facing additions in this milestone include high-detail Frontier materials and atmosphere, three mining modes (Block/Micro/Mixed), physical 8×8×8 microvoxel carving, living grass and flowers, collectible world drops, a real survival inventory/hotbar, inventory-backed placement, ornate native inventory presentation, and schema-3 persistence for the new state.
