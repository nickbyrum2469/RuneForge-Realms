# 0.5.3 hardware checklist

1. In first person with an empty hotbar slot selected, both hands should peek naturally from the bottom corners at idle and while walking.
2. With a block/item selected, only the dominant right hand and held item should be visible.
3. Turn left/right/up/down continuously. Hand/item geometry must stay locked to the camera and must not counter-rotate.
4. LMB must begin from the already-visible rest hand, swing through the center crosshair, follow through, and return without popping.
5. Test a close block and a farther reachable block. The visual strike depth should adapt while impact remains on the center-crosshair-selected block.
6. Place an unrelated block beside the crosshair target. The swing must not hit the side block.
7. F3 third person should orient the full character from the same canonical look direction rather than an opposite yaw convention.
8. Send screenshots/video for final tuning before any 0.5.3 release.
