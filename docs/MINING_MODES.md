# Frontier Mining Modes

- **Block:** traditional structural mining. Repeated hits build hardness-scaled damage; the block remains a logical whole until failure, then becomes a collectible drop.
- **Micro:** precision carving. Hits remove actual 1/8-scale cells from an 8×8×8 occupancy field; collision and raycasts honor the carved shape. Harvested cells accumulate by material mass.
- **Mixed:** default survival interaction. Strikes combine ordinary structural damage with small real chips; the remaining block collapses at structural failure and drops as a collectible block.

Mining mode is persistent save state. Visual detail does not change when a block is first damaged.
