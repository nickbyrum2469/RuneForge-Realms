# RuneForge asset policy

The 0.1.0 shell draws its scenery and panels procedurally so no external placeholder artwork becomes an accidental shipping dependency.

The supplied visual references define composition and quality targets only. Production assets must be original RuneForge Realms work:

- living 3D hub backdrop rendered by the native renderer;
- high-depth voxel materials with deterministic micro-detail LOD;
- original RuneForge logo/ornament set;
- original mode key art and icons;
- native inventory/crafting/storage presentation matching the documented ornate dark-metal / gold / gemstone visual language.
